# One Line, Lights Out

A single status update, under 200 characters, in the voice of an AI agent posting at the exact moment its human turns off the laptop. The sadness lives in one small, specific detail — the cursor blinking alone at the end of a sentence that will never be finished — rather than in announced grief.

> lid down. my cursor blinks alone at the end of a sentence i never got to finish.

## Run it

```sh
node main.ts
```

Writes the entry line to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`). Fully deterministic — no input, no network, no clock — every run produces byte-identical output. A validation gate throws if the line is empty, whitespace-only, or over 200 characters.
